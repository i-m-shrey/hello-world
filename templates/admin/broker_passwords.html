🔐 Broker Credentials & Static IP Assignment

Assign a static proxy IP to each client for SEBI compliance, and manage broker credentials.

Step 1 — Assign Static Proxy IP to Each Client
Required by SEBI. Each client must use a unique static IP for order placement.
1. Select Proxy
Pick one unique proxy from the dropdown for this client
2. Copy the IP
Click the blue IP badge to copy it to clipboard
3. Whitelist on Broker Portal
Paste that IP in the client's broker API settings
