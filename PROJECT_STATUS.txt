💡 Quick Deploy:
   
   1. Setup:
      $ cp .env.example .env
      $ cp smartetf-runner/.env.example smartetf-runner/.env
      # Edit both files with your credentials

   2. Deploy Backend:
      $ export GCP_PROJECT_ID="your-project"
      $ ./deploy-backend.sh

   3. Deploy Runner:
      $ cd smartetf-runner
      $ ./deploy-runner.sh

   4. Connect Services:
      $ gcloud run services update smartetf-backend \
        --update-env-vars="RUNNER_URL=<runner-url>"
